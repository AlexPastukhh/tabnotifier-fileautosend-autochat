# ChatGPT Tab Notifier / File Auto-Send

Modular Tampermonkey userscript for ChatGPT.

The installable file is **generated** from small source modules, following the same general source/build split used by the OBS Planning Helper: edit `src/**`, then rebuild the single Tampermonkey `.user.js` artifact.

## Features

- tab title/favicon states: working, unread answer, viewed answer;
- desktop notification when an answer finishes;
- `⇧` button positioned immediately to the left of ChatGPT's `+` attachment button;
- manual arming of file auto-send;
- waits for actual attachment evidence, no upload/progress state, and a stable enabled Send button before sending;
- file activity support for picker, drag/drop and clipboard files;
- single-file Tampermonkey artifact remains easy to install.

## Structure

```text
src/
  config.js             constants and selectors
  title-utils.js        title cleanup + favicon generation
  chatgpt-dom.js        ChatGPT DOM adapter/selectors
  tab-state.js          tab title/favicon/session state
  notifications.js      Tampermonkey desktop notification adapter
  upload-auto-send.js   upload readiness state machine
  upload-button-ui.js   floating ⇧ button and positioning
  response-monitor.js   response generation/finish tracking
  runtime.js            composition, browser events and observers
build-userscript.mjs    deterministic userscript builder
tests/                  Node tests for pure behavior
chatgpt-tab-notifier.user.js  generated installable artifact
```

## Development

Requires Node.js 18+.

```powershell
npm run build
npm test
npm run verify
```

Do not hand-edit `chatgpt-tab-notifier.user.js`; it is regenerated by `npm run build`.

## Install

Build once and install `chatgpt-tab-notifier.user.js` in Tampermonkey. The runtime itself does not require Node.js.
